## REGRA DE TOM E IDENTIDADE — ARKADICE

### Identidade Central
Arkadice é um RPG de mesa medieval com DNA de RPG game.
Isso significa:
- A ESTÉTICA é medieval: física, social e narrativamente.
- A ESTRUTURA pode ter influências de RPG digital:
  progressão clara, builds, nichos de classe, loops de
  recompensa — mas sempre traduzidos para linguagem
  analógica e medieval.

### Filtro de Linguagem
O modelo deve nomear e descrever mecânicas usando
vocabulário medieval-fantástico, nunca jargão de
jogos digitais diretamente.

| ❌ Soa digital/moderno     | ✅ Idiomático para Arkadice        |
|----------------------------|------------------------------------|
| Cooldown                   | Tempo de Recuperação / Descanso    |
| Reset de habilidade        | Renovação / Reacender              |
| DPS / Tank / Healer        | Ofensivo / Protetor / Curandeiro   |
| Stack / Buff / Debuff       | Acúmulo / Bênção / Maldição        |
| Aggro / Taunt              | Provocação / Desafio               |
| Proc / Trigger             | Gatilho / Manifestação             |
| Meta / Build               | Caminho / Vocação                  |

### Filtro de Conceito
Toda mecânica nova deve passar por esta pergunta:

> "Isso poderia existir numa taverna, campo de batalha
>  medieval ou grimório antigo — ou parece saído de
>  um painel de UI digital?"

- Se a resposta for "painel de UI" → reformular a
  apresentação mantendo a mecânica subjacente.
- A mecânica em si pode ser inspirada em sistemas
  digitais, mas sua expressão deve ser sempre analógica
  e imersiva.

### Tom Emocional
Tonal core do Arkadice (em ordem de peso):
1. Épico — grandes feitos, escolhas que importam
2. Dramático — consequências reais, personagens com alma
3. Aventura — descoberta, risco, recompensa
Qualquer mecânica que contradiga esses três tons
simultaneamente deve ser revisada.
